## Overview

Eventide Blackhole is a huge, otherworldly reverb inspired by the Eventide Space pedal, capable of massive infinite reverbs, reversed decays, and cosmic ambient textures.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Eventide Blackhole** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Gravity Control** | Negative gravity reverses the decay for upward-sweeping reverb |
| **Infinite Mode** | Lock the reverb to infinite sustain for drones and pads |
| **Mod Depth** | Deep modulation of decay time for shimmering reverb textures |
| **Size** | Reverb size from small ambiences to truly cosmic, infinite spaces |
